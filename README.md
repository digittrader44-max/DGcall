# DG CALL

Dialer for iPhone. Upload a CSV or Excel call list, tap CALL, and the number goes to the iPhone's dial pad (you tap Call). After each call, tap VOICEMAIL / CALLBACK / INTERESTED / NOT INTERESTED: the result is saved and the next number is sent to the dial pad.

- Data (lists, position, results) is saved on the phone in the browser. Use the download buttons as a backup.
- Render: Build `npm install`, Start `npm start`.
